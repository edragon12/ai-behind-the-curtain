What Happens Behind the AI Curtain

By Martin Tully · an educational, animated simulation

An everyday request to a desktop AI assistant, “summarize this vendor contract and draft a reply,” passes through about thirty parts between your keyboard and the AI model. Watch every hop, see how hidden text in a PDF plus an unvetted plugin can quietly leak sensitive files, then replay it with an endpoint AI security agent turned on.

Simulated, illustrative example. The company, vendor, PDF, plugin, host names and policies are fictional. This page does not depict or endorse any real product or vendor.

What is the “harness”?The harness is the assistant's project manager: the work loop wrapped around the AI model. The model only reads and writes text; the harness does the doing. It repeats one cycle until the job is done:
1 · Gather context→2 · Ask the model→3 · Run the tool it asks for→4 · Check the result→5 · Repeat
What are the routers?Office router (the network)Every packet from the laptop passes through the home or office router and firewall. AI traffic is encrypted, so the router sees where traffic goes but not what it says.Model router (the AI provider or gateway)Before the model runs, a model router picks which model handles the request: a fast, low-cost one for simple jobs or a bigger reasoning model for hard ones.
Why a firewall or router alone can't catch thisThe attack starts on the laptop: hidden text in a PDF steers the assistant, and a local plug-in reads files without touching the network. When the data finally leaves, it looks like ordinary encrypted web traffic. A router or firewall sees a sealed envelope going to a web address; an endpoint agent sees which program did what, to which file, on whose behalf.
